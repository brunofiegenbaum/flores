# Cadastro de Flores

Aplicativo de cadastro de flores feito com React Native, Expo Router e SQLite, seguindo o padrão do projeto de aula [Aula-25-09](https://github.com/brunofiegenbaum/Aula-25-09).

## Funcionalidades

- Cadastrar nome, cor predominante e nome científico.
- Listar as flores cadastradas.
- Excluir uma flor com confirmação.
- Editar os dados de uma flor.
- Salvar os registros localmente no banco `flores.db` (SQLite).

## Como executar

É necessário ter Node.js instalado.

```bash
npm install
npx expo start
```

Abra o aplicativo no Expo Go ou em um emulador compatível com a versão do Expo instalada.

O código principal está em `src/app/index.js`.
